[WordPress](https://wordpress.org/) 是使用 PHP 编写的开源 CMS，适合建站、博客与扩展开发。

## 安装

1. **下载**：从 [wordpress.org 下载](https://wordpress.org/download/) 压缩包，或使用 WP-CLI：
   ```sh
   wp core download
   ```
2. **环境**：需 PHP、MySQL/MariaDB 与 Web 服务器（如 Nginx、Apache）。
3. **安装向导**：将文件放到站点目录后，在浏览器访问站点，按提示创建数据库、填写站点信息完成安装。

主机面板（如 cPanel、宝塔）通常提供「一键安装 WordPress」，可按面板说明操作。

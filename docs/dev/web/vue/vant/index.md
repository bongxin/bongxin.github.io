# Vant

[Vant](https://vant-ui.github.io/vant/) 是有赞出品的轻量、可靠的移动端 Vue 组件库，支持 Vue 3。

## 安装

```sh
npm i vant
```

按需引入时推荐使用 [unplugin-vue-components](https://github.com/antfu/unplugin-vue-components) 等插件自动按需注册。

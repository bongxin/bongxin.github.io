[Obsidian](https://obsidian.md/) 是一款以本地 Markdown 文件为核心的知识库与笔记应用，支持双向链接、关系图谱、插件扩展与多设备同步，适合个人知识管理与长期写作沉淀。

## 使用

### 安装

- **桌面端**：在 [obsidian.md/download](https://obsidian.md/download) 下载 Windows / macOS / Linux 客户端。
- **移动端**：App Store / Google Play 搜索 Obsidian，与桌面端通过官方同步或第三方方案联动。

### 基本流程

1. **创建仓库（Vault）**：首次打开选择或新建一个本地文件夹作为笔记库，所有 `.md` 文件保存在该目录。
2. **写笔记**：新建笔记即 Markdown 文件，支持 `[[双向链接]]`、`#标签`、代码块、公式等。
3. **图谱与反向链接**：通过关系图谱查看笔记关联；右侧面板可查看当前笔记的入链与出链。
4. **插件与主题**：设置 →「第三方插件」→ 开启社区插件市场，按需安装日历、模板、Dataview 等扩展。

### 与本文档站的关系

本站基于 VuePress 2 + Plume 主题构建，Obsidian 同样以 Markdown 为底层格式，适合：

- 在 Obsidian 中起草、整理碎片笔记
- 成熟内容再迁移或同步到本站文档库发布

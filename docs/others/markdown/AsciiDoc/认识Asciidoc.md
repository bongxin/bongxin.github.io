---
title: 认识 AsciiDoc
---

[AsciiDoc](https://asciidoc.org/) 是一种面向文档的标记语言，语法比 Markdown 更丰富，适合技术手册、书籍与复杂排版，可导出 HTML、PDF 等格式。

## 与 Markdown 的区别

- 支持更细粒度的标题、表格、脚注、交叉引用
- 原生支持文档属性、条件包含、目录生成
- 常用于 Antora、Asciidoctor 等文档工具链

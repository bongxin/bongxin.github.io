# 认识 Markdown

[Markdown](https://www.markdownguide.org/) 是一种轻量级标记语言，用纯文本编写，可转为 HTML，广泛用于文档、README 与静态站点（如 VitePress）。

## 常用语法

- **标题**：`# 一级` ~ `###### 六级`
- **强调**：`**粗体**`、`*斜体*`
- **列表**：`- 无序`、`1. 有序`
- **链接**：`[文字](URL)`
- **代码**：行内 `` `code` `` 或围栏代码块 ` ```lang `

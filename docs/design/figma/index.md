[Figma](https://www.figma.com/) 是面向团队的协作式 UI 设计工具，支持界面设计、原型、开发标注与实时协作，可在浏览器或桌面端使用。

## 使用

- **网页版**：打开 [figma.com](https://www.figma.com/) 注册/登录即可在浏览器中设计，无需安装。
- **桌面端**：在官网下载 [Figma 桌面应用](https://www.figma.com/downloads/)，适合大屏与离线使用，与网页版数据同步。
- **协作**：邀请成员进入同一文件即可实时编辑、评论；可通过链接分享只读或可编辑权限。

在 Proxmox VE 上创建飞牛 fnOS 虚拟机（实装 VMID **100**）。管理入口：[PVE](https://192.168.31.2:8006/) · Web：[飞牛fnOS](http://192.168.31.186:5666/)。

## 上传 ISO 到 local

1. 打开 PVE → 节点 → **存储** → **local (pve)**。
2. **ISO 镜像** → **上传**，选择飞牛官网下载的 `.iso`。
3. 上传完成后在 ISO 列表中可见。

`local` 为目录型存储，适合放 ISO / CT 模板 / 备份，不作为虚拟机运行盘。

## 创建虚拟机

右上角 **创建虚拟机**，建议参数：

| 步骤 | 建议 |
|------|------|
| 常规 | 名称如 `fnOS`；VM ID 自定 |
| 操作系统 | 使用 CD/DVD；存储 **local**；选飞牛 ISO；类型 Linux · 版本 6.x - 2.6 Kernel |
| 系统 | 机型 **q35**；BIOS SeaBIOS；SCSI 控制器 **VirtIO SCSI single** |
| 磁盘 | 总线 SCSI；存储 **local-zfs**；大小建议 ≥ **64GB**；格式保持 **raw**（ZFS 锁定，正常） |
| CPU | ≥ 2 核；类别可用默认或 host |
| 内存 | ≥ **4096 MB** |
| 网络 | VirtIO · 桥接 **vmbr0**；可先不勾防火墙 |

确认页示例（实装）：

- 磁盘：`scsi0: local-zfs:64,iothread=on`
- 内存：`4096`
- 网卡：`virtio,bridge=vmbr0`
- 已挂载飞牛 ISO

点 **完成** 后启动虚拟机，再进控制台安装。

### 关于磁盘格式

选 `local-zfs` 时格式会强制为 **raw**。zvol 块设备走 ZFS 原生快照 / 克隆，性能也更好；不要强求 qcow2。

## 安装系统

1. 选中虚拟机 → **启动** → **控制台**（noVNC）。
2. 选 Graphical Install，按向导完成分区与账号。
3. 系统分区建议约 24GB；剩余空间留给后续存储空间。
4. 安装结束重启前：在虚拟机 **硬件** → **CD/DVD 驱动器** → **不使用任何介质**，再重启，避免再次进安装界面。

## 首次访问

控制台通常会显示类似：

| 项 | 实装 |
|----|------|
| VMID | `100` |
| IP | `192.168.31.186`（DHCP；目标对齐末段 = VMID 为 `.100`） |
| Web | `http://192.168.31.186:5666` |

浏览器打开 Web 走初始化向导（设备名、管理员账号）。建议改为静态 IP 或 DHCP 绑定，并逐步与 VMID 末段对齐。

## 后续可选

| 项 | 说明 |
|----|------|
| 数据盘 | 再挂一块 `local-zfs` 虚拟盘做数据，与系统盘分离 |
| 硬盘 / 核显直通 | 物理盘或 AMD 680M 硬解再单独配置 |
| 快照 | 利用 ZFS 快照定期备份虚拟机 |

总览见 [Proxmox VE](/ops/proxmox/)。

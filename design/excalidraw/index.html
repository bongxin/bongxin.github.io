Excalidraw

约 252 字小于 1 分钟

Excalidraw 是一款开源的手绘风格白板绘图工具，适合快速画流程图、架构图、线框图与头脑风暴草图，支持浏览器直接使用与协作分享。

使用

  • 网页版：打开 excalidraw.com 即可开始绘图，无需注册；也可登录账号同步到云端。
  • 桌面端：从 GitHub Releases 下载桌面应用，适合本地离线使用。
  • 常用操作：左侧选择形状/箭头/文字，拖拽绘制；选中元素可调整样式、分组、对齐；支持导出 PNG / SVG / .excalidraw 源文件。
  • 协作：通过「分享」生成链接，他人可实时查看或共同编辑（需登录 Excalidraw 账号）。

适用场景

  • 产品流程、页面跳转、系统架构的快速示意
  • 会议讨论时的现场画图与标注
  • 需要「手绘感」、弱化正式 UML 语法时的草图表达
